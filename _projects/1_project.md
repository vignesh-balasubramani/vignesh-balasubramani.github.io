- Built a multi-camera test rig with intrinsic and extrinsic calibration and time synchronization for aligned multi-view capture.
- Built an automatic scene recognition and annotation workflow powered by a vision-language model to label an industrial assembly multimodal dataset.
- Ran ablation studies over camera-view count, prompt structure and temporal window size, raising zero-shot step-recognition accuracy from 8% to 44.5% frame accuracy.
- Ran batch inference and evaluation on Linux GPU clusters with Slurm, Git versioning and CI/CD.

**Stack:** Python, PyTorch, Hugging Face Transformers, OpenCV, Slurm, Linux.
